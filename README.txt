MINI MANIA — standalone site

What's in here
  index.html   the whole game
  audio/       the four stems of "Rhythm of the Night" (vocals, drums, bass, other)

Put it online (free; the camera needs an https site)
  Netlify Drop (fastest)
    1. Unzip this folder.
    2. Go to https://app.netlify.com/drop and drag the unzipped folder onto the page.
    3. Sign in or create a free account when asked, so the site stays up.
    4. Open the https link it gives you.
  GitHub Pages
    1. Create a new repository and upload index.html and the audio folder.
    2. Settings > Pages > Deploy from branch > main / root > Save.
    3. Open https://<your-username>.github.io/<repository-name>/ after a minute.

Using the face-cam
  In the lobby, press "Face-cam" and allow the camera when the browser asks.
  Turn on "Record run" too, and your clip saves as a split-screen:
  your run on top, you on the bottom.

Note: opening index.html straight from your computer (file://) won't load the songs or the camera.
Use one of the hosts above, or any local web server.
